PROJECT DOCUMENTATION -- Python Assignment 3
Project Overview - This project contains Python code for a number guessing game, a multiplication table generator, and a BMI calculator.
Tools used - IDLE(Python)
Steps followed :- 
NUMBER GUESSING NAME - * Generated a random number between 1 and 10 that the user has to guess.                          *Set a variable attempts to 3, which is the maximum number of guesses allowed.                                            *Used  while loop to allow the user to keep guessing.                                                                    *Used continue and break to skip and exit the loop respectively.                                                         MULTIPLICATION TABLE GENERATOR - *Asked the user to enter a number.                                                      *Used a for loop with range(1, 11) to go through 1 to 10.                                                                *Calculated the product in each iteration and printed it in the format number x i = result.                              BMI CALCULATOR - *Defined a function calculate_bmi(weight, height) that returns weight / (height ** 2).                  *Took weight (kg) and height (m) as input from the user.                                                                 *Called the function and displayed the BMI.
